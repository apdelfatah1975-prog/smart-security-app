# الإدارة الذكية — Smart Security Life

تطبيق ويب تقدمي عربي باتجاه RTL لإدارة الأمن الشخصي والعملي والمالية والديون وشؤون الأبناء والدروس، مع قسم شخصي مستقل باسم «مركباتي». صُمم التطبيق بأسلوب Mobile-First ليعمل على الهاتف والكمبيوتر، ويمكن تثبيته كتطبيق PWA.

## الوحدات الحالية

| الوحدة | الوظائف الرئيسية |
| --- | --- |
| إدارة الأمن | سجل أفراد الأمن، كود بحث، بيانات الهوية والاتصال، الترخيص والسلاح والمعاش، أماكن العمل والتنقلات، الحضور والورديات، المرور والتفتيش، وخطة مرور شهرية قابلة للنسخ والمشاركة والاستعلام. |
| المالية | الإيرادات والمصروفات والتصنيفات وحساب صافي الخزينة. |
| الديون | مبالغ مستحقة لك، التزامات واجبة السداد، الدفع الجزئي، وتواريخ الاستحقاق. |
| الأبناء والدروس | ملفات الأبناء والمدرسين، مواد الدراسة، مواعيد الحصص وتكلفة كل حصة. |
| مركباتي | بياناتك الشخصية فقط للسيارة أو الموتوسيكل أو التوك توك أو أي نوع آخر، مع الشراء والبيع والرخص وسجل الفحص والتجديد والسحب. لا تظهر هذه البيانات في ملفات الحراس. |
| التقارير | طباعة وتصدير عربي للملخصات والتقارير الأساسية إلى PDF وExcel وفق وظائف التصدير الموجودة في المشروع. |

## التقنية

React 19 وTypeScript وVite وTailwind CSS 4 وtRPC 11 وDrizzle ORM وMySQL/TiDB، مع خط عربي وتخطيط RTL وservice worker خفيف يدعم التثبيت والتهيئة الأساسية دون تخزين استجابات API قديمة.

## التشغيل المحلي

```bash
pnpm install
pnpm dev
```

للفحص:

```bash
pnpm test --run
pnpm exec tsc --noEmit
pnpm run build
```

يتطلب التشغيل المركزي متغيرات البيئة التي يوفرها قالب Manus، وأهمها `DATABASE_URL` و`JWT_SECRET`. لا تُحفظ الأسرار داخل المستودع، ويجب ضبطها من بيئة التشغيل أو إعدادات المشروع.

## المزامنة والتخزين

تستخدم الواجهة التخزين المحلي كنسخة مؤقتة للاستجابة السريعة، بينما يحاول التطبيق جلب اللقطة المركزية وحفظ السجلات عبر إجراءات tRPC. صور أفراد الأمن وصور المرور تُنظَّف وتُتحقق من نوعها وحجمها ثم تُرفع إلى التخزين المركزي ويُحفظ الرابط بدلاً من إبقاء Data URL داخل السجل.

## ملاحظات الجدولة والتنبيهات

تظهر تنبيهات الرخص التي تقترب من الانتهاء قبل شهرين عند فتح التطبيق، مع رسالة عربية وإمكانية تشغيل تنبيه صوتي. أما الإرسال الدوري خارج جلسة المتصفح فيحتاج إلى تشغيل مهمة مجدولة في بيئة النشر، ولا يعتمد على مؤقت داخلي داخل صفحة React.

## الخصوصية

الرقم القومي وأرقام الرخص والسلاح وبيانات المركبات معلومات حساسة. استخدم حساباً محمياً، واضبط صلاحيات قاعدة البيانات والتخزين، ولا تضع أي رمز وصول أو كلمة مرور في ملفات المصدر أو سجل Git.
